# Surface brief: website (apps/website) and player skins

Scope: whole site (landing = Persuade; skins gallery/detail = Experience; docs = Read; playground = Operate) plus the shared player base CSS and all nine skins.
Audience: media / OTT / LMS teams choosing a player; secondary frontend devs.
Job: believe "skins are the product" within one viewport, then try a skin and copy code.
Keep: Astryx components, tomato red identity, dark-first.

## Direction contract

THESIS: The site is a numbered edition catalogue. Each skin is a release, No.01 to No.09, shown at cover scale as a live player with its colophon. Refuses the dev-tool hero plus feature-card grid.

OWN-WORLD: Lacquer-black warm ground (#0e0c0b), raised warm surfaces, warm hairline rules. Tomato red (#e5402c) is the house colour: edition numbers, active marks, primary actions. Each edition carries its own accent only on its own spread. Bricolage Grotesque display (tight, heavy numerals), Geist body, Geist Mono only for code. Small 6-10px corners, rules over boxes.

STORY: One engine, nine complete interfaces; pick an edition, watch it change live, read its colophon, copy the install line.

FIRST VIEWPORT: Left: headline, one-sentence lead, Get started + All editions. Right two-thirds: live player at cover scale, colophon beside it (huge edition number, name, size, accent chip, best-for). Below: the edition strip, nine numbered thumbnails; selecting one swaps the live skin.

FORM: Collection (user-chosen from three directions plus canon). seed: none (unavailable)

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
