# tomato-player

Tomato Player — one player, a thousand possibilities. Batteries-included bundle: core, UI, every official skin and plugin, and the <tomato-player> web component.

## Install

```sh
npm i tomato-player
```

## Usage

```html
<script src="https://cdn.jsdelivr.net/npm/tomato-player"></script>
<tomato-player src="movie.mp4" skin="cinema" title="My film"></tomato-player>
```

Or with a bundler: `import { createPlayer, minimal, hotkeys } from 'tomato-player'`.
